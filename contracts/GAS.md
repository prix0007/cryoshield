# Contracts gas

Measured with forge 1.1.0, solc 0.8.28, optimizer 10,000 runs, EVM `cancun`. Every figure below comes from the
committed per-call snapshots (`snapshots/*.json`, written by `vm.snapshotGasLastCall`), which CI checks are unchanged
after `forge test`. The table is generated by `script/gas-md.sh`; CI runs `script/gas-md.sh --check`, so this file cannot
drift from the snapshots. Write paths ("full tx") run with `isolate = true`: each figure is one call run as its own
transaction (21,000 intrinsic gas, calldata and cold storage included). `.gas-snapshot` separately holds the v1
per-test totals (`forge snapshot --mc GasTest --check`).

## Notes

- **VaultRegistry v1:** the worst case per call is bounded by its caps (at most 8 locators, each scanning at most 15
  existing entries). Its CREATE2 deployment was measured once by hand at about 0.87M gas (3,845-byte runtime) and is
  not snapshotted.
- **VaultRegistryV2:** registration cost does not depend on how long a locator's list is
  (`test_appendCostIndependentOfListLength`); `addLocators` costs one slot more than v1 for the per-vault duplicate set.
  `getVaults` of 32 x 1 KB fits public RPC `eth_call` gas caps.
- **CryoShieldSmartWallet validation** is measured with the software P-256 fallback (the test EVM has no RIP-7212
  precompile). On OP chains the precompile (about 3,450 gas) replaces it, so both `validateUserOp` figures drop by
  roughly 200k. The extra checks (length, rpIdHash comparison, UV bit) cost well under 1k gas; the remaining gap to
  Coinbase's deployed v1.1 comes from the two builds' different compiler settings.

## Estimated cost (VaultRegistry v1 direct calls)

> **Assumptions, not measurements:** derived from the v1 "full tx" figures above. ETH = $3,000. Arbitrum One L2 gas
> price = 0.01 gwei (the network floor). Ethereum L1 gas price = 1 gwei (quiet) or 10 gwei (busy). Rescale linearly.

| Operation | Arbitrum L2 execution | Ethereum L1 @ 1 gwei | Ethereum L1 @ 10 gwei |
|---|---:|---:|---:|
| create (1 KB, 2 locators) | 0.0000091 ETH ≈ **$0.027** | 0.00091 ETH ≈ $2.74 | 0.0091 ETH ≈ $27.38 |
| update (1 KB) | 0.0000021 ETH ≈ **$0.006** | 0.00021 ETH ≈ $0.64 | 0.0021 ETH ≈ $6.36 |
| add 1 locator | 0.00000075 ETH ≈ **$0.002** | 0.000075 ETH ≈ $0.22 | 0.00075 ETH ≈ $2.24 |

Arbitrum also charges an L1 data-posting component for the roughly 1.2 KB of compressed calldata. Ciphertext does
not compress, so expect about 1.2 KB per create or update. Post-EIP-4844 this has typically been about a cent or less,
but it varies with L1 blob fees and is **not measured here**; real per-operation costs on OP Sepolia are recorded by
harden-gas-sponsorship task 6.3 in `apps/web/docs/costs.md`. ERC-4337 adds EntryPoint and account-validation
overhead on top of these direct-call figures.
